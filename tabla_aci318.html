1. FACTORES DE MAYORACIÓN DE CARGAS (ACI 318 §5.3)

Combinaciones de carga mayoradas para el diseño por resistencia.

CombinaciónFórmula
BásicaU = 1.4 D
Con carga vivaU = 1.2 D + 1.6 L + 0.5 (Lr o R)
Con vientoU = 1.2 D + 1.0 W + L + 0.5 (Lr o R)
Con sismoU = 1.2 D + 1.0 E + L
Contra vientoU = 0.9 D + 1.0 W
Contra sismoU = 0.9 D + 1.0 E

Notación

  • D = carga muerta
  • L = carga viva
  • Lr = carga viva de cubierta
  • R = carga de lluvia
  • W = carga de viento
  • E = carga sísmica
