3. COMBINACIONES DE CARGA (NEC-15, CAPÍTULO 3)

Para el estado límite de resistencia, la NEC-15 establece las siguientes combinaciones:

3.1 Combinación básica (más usada)

Cu = 1.2 D + 1.6 L

Donde:

  • 1.2 = factor de mayoración para carga muerta (D)
  • 1.6 = factor de mayoración para carga viva (L)

3.2 Otras combinaciones

1.4 D
1.2 D + 1.6 L + 0.5 (Lr o R)
1.2 D + 1.0 W + L + 0.5 (Lr o R)
1.2 D + 1.0 E + L
0.9 D + 1.0 W
0.9 D + 1.0 E

¿Por qué se mayoran las cargas?

Porque las cargas reales pueden ser mayores que las estimadas. Los factores de seguridad garantizan que la estructura no falle por flexión, cortante o deflexión excesiva.
