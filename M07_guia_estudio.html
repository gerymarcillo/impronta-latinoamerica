1. PRESENTACIÓN DEL MÓDULO

Este módulo introduce el análisis dinámico modal aplicado al pórtico de 2 pisos del proyecto, utilizando la NEC-15 y el ACI 318-19.

El análisis modal permite determinar las frecuencias naturales, períodos y formas modales de la estructura, que son esenciales para el diseño sismorresistente.

A diferencia de un software comercial (ETABS, SAP2000, Revit), este módulo integra:

  • Análisis analítico: matrices de rigidez K y masa M
  • Análisis estocástico: Monte Carlo (N=1000) con confiabilidad β
  • Validación experimental: Phyphox + filtro de Kalman
  • Hardware: ADXL345 + ESP32 (sismógrafo de bajo costo)
  • 5 TIC de Análisis Dinámico (criterios de diseño)

Duración estimada: 60 minutos (cuestionario) + 120 minutos (guía)

2. OBJETIVOS DE APRENDIZAJE

Objetivo general

Analizar el comportamiento dinámico del pórtico de 2 pisos mediante el método modal, calculando sus frecuencias naturales, períodos y formas modales, y validando los resultados con datos experimentales del acelerómetro.

Objetivos específicos

  • Construir la matriz de rigidez K y la matriz de masa M
  • Calcular las frecuencias naturales ω₁ y ω₂
  • Determinar los períodos T₁ y T₂
  • Identificar las formas modales φ₁ y φ₂
  • Aplicar el filtro de Kalman para reducción de ruido
  • Comparar el período teórico con el experimental (Phyphox)
  • Aplicar los 5 TIC de Análisis Dinámico

3. FUNDAMENTO TEÓRICO

3.1 ¿Qué es el análisis modal?

Es el proceso de obtener las frecuencias naturales, períodos y formas modales de una estructura. Se basa en resolver el problema de autovalores:

K · φ = ω² · M · φ

3.2 Matriz de rigidez K (shear building)

Para un pórtico de cortante de 2 pisos, cada piso tiene una rigidez k:

k = n_col · 12 · E · I_col / He³

La matriz de rigidez acopla los desplazamientos de los pisos:

K = ⎡ 2k -k ⎤ ⎣ -k k ⎦

3.3 Matriz de masa M

Modelo de masa concentrada (lumped mass):

m = Cu · At / g
M = ⎡ m 0 ⎤ ⎣ 0 m ⎦

3.4 Frecuencias naturales (analíticas)

Para el shear building de 2 pisos:

ω₁² = (k/m) · (2 - √2) ≈ 0.586 · k/m
ω₂² = (k/m) · (2 + √2) ≈ 3.414 · k/m

3.5 Períodos y frecuencias

T₁ = 2π / ω₁ | f₁ = ω₁ / (2π)
T₂ = 2π / ω₂ | f₂ = ω₂ / (2π)

3.6 Filtro de Kalman

Algoritmo que reduce el ruido de una señal preservando su información útil:

Predicción: x_pred = x[k-1] ; P_pred = P[k-1] + Q
Actualización: K = P_pred / (P_pred + R)
x[k] = x_pred + K · (z[k] - x_pred)

3.7 Validación experimental (Phyphox)

La frecuencia experimental se obtiene del pico de la FFT:

f_exp = argmax(FFT(señal_filtrada))

Se compara con la frecuencia teórica f₁ (error aceptable ± 10%).

6. EJEMPLO RESUELTO PASO A PASO

Datos del problema (Pórtico del proyecto)

  • L1, L2, L3, L4 = 5.5, 6.0, 5.5, 6.0 m
  • He = 3.0 m
  • b_col × h_col = 0.38 × 0.38 m
  • fc = 210 kg/cm²
  • Cu = 1.088 t/m²
PASO 1: Módulo de elasticidad
E = 15100·√210 = 218,819 kg/cm² = 2,188,190 t/m²
PASO 2: Inercia de columna
I_col = 0.38 · 0.38³ / 12 = 0.000217 m⁴
PASO 3: Área tributaria
At = (5.5/2 + 6.0/2) · (5.5/2 + 6.0/2) = 5.75 · 5.75 = 33.06 m²
PASO 4: Masa por piso
m = Cu · At / g = 1.088 · 33.06 / 9.81 = 3.667 t·s²/m
PASO 5: Rigidez de entrepiso
k = 4 · 12 · 2,188,190 · 0.000217 / 3³ = 22,171 t/m
PASO 6: Matriz de rigidez K
K = ⎡ 2k -k ⎤ = ⎡ 44,342 -22,171 ⎤
⎣ -k k ⎦ ⎣ -22,171 22,171 ⎦
PASO 7: Matriz de masa M
M = ⎡ 3.667 0 ⎤
⎣ 0 3.667 ⎦
PASO 8: Autovalores
k/m = 22,171 / 3.667 = 6,046
ω₁² = 0.586 · 6,046 = 3,543 → ω₁ = 22.43 rad/s
ω₂² = 3.414 · 6,046 = 20,641 → ω₂ = 69.05 rad/s
PASO 9: Períodos
T₁ = 2π/22.43 = 0.280 s
T₂ = 2π/69.05 = 0.091 s
PASO 10: Frecuencias
f₁ = 22.43/(2π) = 3.571 Hz
f₂ = 69.05/(2π) = 10.99 Hz

7. LOS 5 TIC DE ANÁLISIS DINÁMICO

Un análisis dinámico bien ejecutado cumple 5 criterios:

TIC 1: T experimental ≈ T teórico (± 10%)

Valida el modelo teórico con datos reales.

T_exp = 0.285 s vs T₁_teórico = 0.280 s ✅ CUMPLE

TIC 2: f₁ en rango esperado (0.5–20 Hz)

Verifica que la frecuencia es físicamente razonable.

f₁ = 3.571 Hz ✅ CUMPLE

TIC 3: Amortiguamiento estimado (< 10%)

Controla la disipación de energía.

ζ ≈ 5% ✅ CUMPLE

TIC 4: Relación T₁/T₂ ≈ 3

Verifica la coherencia modal del shear building.

T₁/T₂ = 0.280/0.091 = 3.08 ✅ CUMPLE

TIC 5: Confiabilidad β > 3.5

Verifica que la incertidumbre es baja (Monte Carlo).

β = 4.2 (del análisis estocástico) ✅ CUMPLE

9. EJERCICIOS DE PRÁCTICA

Ejercicio 1: Masa por piso

Calcular m para Cu = 1.20 t/m², At = 30 m².

m = 1.20 · 30 / 9.81 = 3.670 t·s²/m

Ejercicio 2: Rigidez de entrepiso

Calcular k para E = 2.0e6 t/m², I = 0.0002 m⁴, He = 3.0 m, 4 columnas.

k = 4 · 12 · 2.0e6 · 0.0002 / 27 = 21,333 t/m

Ejercicio 3: Período fundamental

Calcular T₁ para k/m = 6,046.

ω₁ = √(0.586 · 6,046) = 22.43 rad/s
T₁ = 2π/22.43 = 0.280 s

Ejercicio 4: Frecuencia

Convertir T₁ = 0.280 s a f₁ (Hz).

f₁ = 1/0.280 = 3.571 Hz

Ejercicio 5: Reflexión final

  1. ¿Por qué el período T₁ es mayor que T₂?
  2. ¿Qué pasaría si T₁ coincide con el período del suelo?
  3. ¿Por qué es importante validar con Phyphox?

1. Porque el modo 1 es el fundamental (menor frecuencia, mayor período).
2. Habría resonancia y amplificación dinámica (riesgo de colapso).
3. Porque confirma que el modelo teórico representa la realidad.
