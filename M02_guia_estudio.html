1. PRESENTACIÓN DEL MÓDULO

Este módulo introduce el concepto de análisis de cargas en estructuras de hormigón armado, aplicando la NEC-15 (Norma Ecuatoriana de la Construcción) y el ACI 318.

El análisis de cargas es el punto de partida de todo diseño estructural: sin conocer las fuerzas que actúan sobre la estructura, no es posible dimensionar vigas, columnas ni losas.

Duración estimada: 60 minutos (cuestionario) + 90 minutos (guía)

2. OBJETIVOS DE APRENDIZAJE

Objetivo general

Calcular las cargas muertas (Cm) y vivas (Cv) de una estructura real, aplicando la NEC-15 y el ACI 318, para obtener la carga última de diseño (Cu).

Objetivos específicos

  • Comprender que toda estructura soporta cargas (peso propio, muros, losa, uso)
  • Aplicar la combinación de carga Cu = 1.2·Cm + 1.6·Cv
  • Clasificar el uso de la estructura según la NEC-15, Tabla 9
  • Conectar el cálculo teórico con un caso real: Proyecto Multidisciplinario UNESUM-REZ-2026-JIPIJAPA-001
  • Calcular W (carga por metro lineal) y Pu (carga axial)

3. FUNDAMENTO TEÓRICO

3.1 ¿Qué son las cargas?

Las cargas son las fuerzas que actúan sobre una estructura. Se clasifican en:

TipoSímboloDescripciónEjemplo
Carga muertaDPeso permanente de la estructuraLosa, muros, acabados
Carga vivaLPeso variable por usoPersonas, muebles, equipos
Carga de vientoWPresión del viento—
Carga sísmicaEMovimiento del terreno—

3.2 Combinaciones de carga (NEC-15, Capítulo 3)

Para el estado límite de resistencia, la NEC-15 establece:

U = 1.2 D + 1.6 L

Interpretación:

  • 1.2 = factor de mayoración para carga muerta
  • 1.6 = factor de mayoración para carga viva

¿Por qué se mayoran? Porque las cargas reales pueden ser mayores que las estimadas. El factor de seguridad garantiza que la estructura no falle.

5. EJEMPLO RESUELTO PASO A PASO

Datos del problema

  • Uso: Vivienda (Cv = 0.20 t/m²)
  • Mampostería: Pesada (0.18 t/m²)
  • Espesor de losa: 25 cm (0.36 t/m²)
  • Proyecto: Proyecto Multidisciplinario UNESUM-REZ-2026-JIPIJAPA-001
  • Caso: Estructuras Especiales
PASO 1: Calcular la carga muerta (Cm)
Cm = losa + acabado sup + acabado inf + instalaciones + mampostería
Cm = 0.36 + 0.04 + 0.04 + 0.02 + 0.18 = 0.640 t/m²
PASO 2: Identificar la carga viva (Cv)
Según NEC-15, Tabla 9, para vivienda: Cv = 0.20 t/m²
PASO 3: Aplicar la combinación de carga
Cu = 1.2·Cm + 1.6·Cv
Cu = 1.2 × 0.640 + 1.6 × 0.200
Cu = 0.768 + 0.320 = 1.088 t/m²
PASO 4: Calcular la carga por metro lineal (W)
b_trib = Lt2 = 5.50 m
W = Cu · b_trib = 1.088 × 5.50 = 5.984 t/m
PASO 5: Calcular el área tributaria (At)
At = (Lv1/2 + Lv2/2) · (Lt1/2 + Lt2/2)
At = (6.00/2 + 5.50/2) · (4.80/2 + 5.50/2)
At = 5.75 · 5.15 = 29.613 m²
PASO 6: Calcular la carga axial (Pu)
Fm = 1.2
Pu = At · Cu · Fm = 29.613 × 1.088 × 1.2 = 38.66 t

Verificación

7. EJERCICIOS DE PRÁCTICA

Ejercicio 1: Vivienda en Jipijapa

Calcular la carga última para una vivienda de 2 pisos con:

  • Losa: 20 cm
  • Mampostería: Pesada
  • Uso: Vivienda (Cv = 0.20 t/m²)

Verificar: ¿Cuánto vale Cu?

Cm = 0.30 + 0.04 + 0.04 + 0.02 + 0.18 = 0.58 t/m²
Cu = 1.2·0.58 + 1.6·0.20 = 0.696 + 0.32 = 1.016 t/m²

Ejercicio 2: Aulas del Colegio Alejo Lascano

Calcular la carga última para las aulas del colegio con:

  • Losa: 25 cm
  • Mampostería: Pesada
  • Uso: Aulas (Cv = 0.29 t/m²)

Pregunta: ¿Es mayor o menor que la vivienda? ¿Por qué?

Cm = 0.36 + 0.04 + 0.04 + 0.02 + 0.18 = 0.64 t/m²
Cu = 1.2·0.64 + 1.6·0.29 = 0.768 + 0.464 = 1.232 t/m²
Es mayor que vivienda porque las aulas tienen mayor carga viva (0.29 vs 0.20).

Ejercicio 3: Bodega

Calcular la carga última para una bodega pesada con:

  • Losa: 25 cm
  • Mampostería: Pesada
  • Uso: Bodega pesada (Cv = 1.20 t/m²)

Reflexión: ¿Por qué la bodega tiene una carga viva tan alta?

Cm = 0.36 + 0.04 + 0.04 + 0.02 + 0.18 = 0.64 t/m²
Cu = 1.2·0.64 + 1.6·1.20 = 0.768 + 1.92 = 2.688 t/m²
La carga viva es alta porque almacena materiales pesados y equipos industriales.

Ejercicio 5: Reflexión final

  1. ¿Por qué la NEC-15 exige mayorar las cargas?
  2. ¿Qué pasaría si no se mayoraran?
  3. ¿Cómo se relaciona la carga última con el diseño del acero?

1. Porque las cargas reales pueden ser mayores que las estimadas.
2. La estructura podría fallar por flexión, cortante o deflexión excesiva.
3. La carga última Cu determina el momento Mmax, que a su vez determina el acero As requerido.
