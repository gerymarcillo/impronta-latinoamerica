1. PRESENTACIÓN DEL MÓDULO

Este módulo introduce el diseño de columnas de hormigón armado sometidas a flexo-compresión, aplicando la NEC-15 y el ACI 318.

La columna es el elemento crítico del pórtico sismorresistente: si falla, colapsa toda la estructura. Por eso su diseño debe ser conservador y verificarse con un diagrama de interacción P-M.

Duración estimada: 60 minutos (cuestionario) + 120 minutos (guía)

2. OBJETIVOS DE APRENDIZAJE

Objetivo general

Diseñar una columna de hormigón armado sometida a flexo-compresión, aplicando los criterios de la NEC-15 y el ACI 318, y verificando su comportamiento mediante el diagrama de interacción P-M.

Objetivos específicos

  • Comprender que la columna es el elemento crítico del pórtico sismorresistente
  • Aplicar el predimensionamiento con Ag = Pu/76
  • Construir el diagrama de interacción P-M (curva continua)
  • Identificar el punto de balance (momento máximo)
  • Diseñar el refuerzo longitudinal y transversal
  • Calcular el confinamiento (Ash) y la zona protegida (Lo)
  • Aplicar el modelo estocástico para cuantificar la incertidumbre

3. FUNDAMENTO TEÓRICO

3.1 Diferencia entre viga y columna

AspectoVigaColumna
SolicitaciónFlexiónFlexo-compresión
Carga axialBajaAlta
MomentoCentroNudos
Falla típicaFlexiónCompresión + Flexión
DiseñoFlexiónDiagrama P-M

3.2 Predimensionamiento

Ag = Pu × 1000 / 76

3.3 Diagrama de interacción P-M

El diagrama se construye resolviendo el equilibrio para cada posición del eje neutro c:

Pn(c) = 0.85·fc·b·β1·c + As·fs' - As·fs
Mn(c) = Pn · e(c)

3.4 Punto de balance

P_bal ≈ P0 / 3
P0 = 0.85·fc·Ag + As·fy

En el punto de balance está el MOMENTO MÁXIMO, no la carga máxima.

3.5 Cuantía mínima

1.2% ≤ ρ ≤ 4%

3.6 Confinamiento (NEC-15)

Ash = max[0.3·bc·Lo·fc/fy·(Ag/bc/pc - 1), 0.09·bc·Lo·fc/fy]

3.7 Zona protegida

Lo = max(45 cm, b_col, h/6)

3.8 Separación de estribos

s_prot = min(d/4, 6·φvar/10, 10 cm)
s_cent = min(d/2, 8·φvar/10, 15 cm)

5. EJEMPLO RESUELTO PASO A PASO

📌 Nota de corrección

El cálculo original del As en la Guía M05 (DOCX) tenía un error aritmético. El valor correcto es As = 20.35 cm² (ρ = 1.41%), validado por el Excel y por los 3 algoritmos del M05.

Datos del problema

  • L1 = 5.5 m, L2 = 6.0 m, L3 = 5.5 m, L4 = 6.0 m
  • Cm = 0.62 t/m², Cv = 0.20 t/m²
  • Pisos = 2
  • He = 3.0 m, H_viga = 0.30 m
  • Fm = 1.2
  • fc = 210 kg/cm², fy = 4200 kg/cm²
  • rec = 2.5 cm, φ_long = 14 mm, φ_esq = 16 mm, φ_est = 10 mm
PASO 1: Calcular el área tributaria (At)
At = (L1/2 + L2/2) × (L3/2 + L4/2)
At = (5.5/2 + 6.0/2) × (5.5/2 + 6.0/2)
At = 5.75 × 5.75 = 33.06 m²
PASO 2: Calcular la carga última (Cu)
Cu = 1.2·(0.62·2) + 1.6·(0.20·2)
Cu = 1.488 + 0.64 = 2.128 t/m²
PASO 3: Calcular la carga axial (Pu)
Pu = At · Cu · Fm = 33.06 × 2.128 × 1.2 = 84.43 t
PASO 4: Calcular el predimensionamiento (Ag_req)
Ag_req = 3·Pu·1000 / (0.85·fc + 0.012·fy)
Ag_req = 3·84.43·1000 / (0.85·210 + 0.012·4200)
Ag_req = 253,290 / 228.9 = 1,106.8 cm²
PASO 5: Sección de columna
b_col = h_col = √Ag_req = √1106.8 = 33.3 cm → 38 × 38 cm
Ag = 38 × 38 = 1,444 cm²
✅ CUMPLE (1444 ≥ 1106.8)
PASO 6: Ancho confinado
bc = 38 - 2(2.5) - 1.0 = 32.0 cm
pc = 38 - 2(2.5) - 1.0 = 32.0 cm
PASO 7: Número de varillas
num = var_a×2 + (var_p-2)×2 = 4×2 + (4-2)×2 = 12 varillas
PASO 8: Área de acero
As = 4·0.00785·φesq² + (12-4)·0.00785·φlong²
As = 4·0.00785·16² + 8·0.00785·14²
As = 8.04 + 12.31 = 20.35 cm²
PASO 9: Cuantía
ρ = As / Ag = 20.35 / 1444 = 1.41%
✅ CUMPLE (1.2% ≤ 1.41% ≤ 4%)
PASO 10: Zona protegida (Lo)
Lo = max(45, max(38, 38), 3.0×16.67)
Lo = max(45, 38, 50) = 50.0 cm
PASO 11: Separación en zona protegida (s_prot)
s_prot = min(6×14/10, 10) = min(8.4, 10) = 8.4 cm
PASO 12: Ash zona protegida
Ash = max[0.3·32·50·210/4200·(1444/32/32 - 1), 0.09·32·50·210/4200]
Ash = max[2.07, 0.72] = 2.07 cm²
PASO 13: Ramas
ramas = 2.07 / (0.00785 × 10²) = 2.64 u
PASO 14: Zona central (Lc)
Lc = 300 - 30 - 28 = 242 cm
PASO 15: Ash zona central
Ash_central = 2.07 cm²
PASO 16: Separación zona central (s_cent)
s_cent = min(6×14/10, 15) = min(8.4, 15) = 8.4 cm
